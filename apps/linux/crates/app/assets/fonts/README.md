# Bundled font

ClipDeck uses the unmodified **Noto Sans Arabic** variable font for all text,
including Latin UI labels. One font file is embedded; there is no separate
monospace or fallback font.

Source: [Google Fonts, revision 7af0d90b4d532ffa4b041937b560c6df4e7b1e95](https://github.com/google/fonts/tree/7af0d90b4d532ffa4b041937b560c6df4e7b1e95/ofl/notosansarabic).
The upstream file is `NotoSansArabic[wdth,wght].ttf`, stored here as
`NotoSansArabic.ttf`. SHA-256:
`63111b5b2e074dd48cc67692e0a2726d86ee94c1c37fe8598257b7b4e87e869e`.

See `OFL-NotoSansArabic.txt` for its SIL Open Font License and copyright notice.
The license is included in both Deb and Snap packages.

This font covers Arabic/Persian and Latin text; it is not a font for every
Unicode script or color emoji.
